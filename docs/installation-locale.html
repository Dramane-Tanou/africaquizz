Africa Quizz

Guide d’installation locale — Windows, Docker Compose et PWA

Ce guide permet à un développeur de démarrer l’API Laravel et la PWA, puis de vérifier le parcours « Jouer 5 questions » sans utiliser de données de production.

1. Prérequis

  • Git.
  • Docker Desktop démarré avec le moteur Linux et Docker Compose v2.
  • Node.js LTS et npm pour la PWA.

Le conteneur API contient PHP, Composer, les extensions PostgreSQL et les dépendances Laravel. Aucun PHP ni Composer n’est requis sur Windows pour suivre ce guide.

2. Récupérer le dépôt et préparer l’API

Ouvrez PowerShell dans le dossier où vous souhaitez travailler :

git clone https://github.com/Dramane-Tanou/africaquizz.git
Set-Location africaquizz
Copy-Item africaquizz-api\.env.example africaquizz-api\.env

Le dépôt GitHub est public : vous pouvez le cloner sans invitation ni accès particulier.

Construisez l’image de développement. Composer installe les dépendances lors de cette étape :

docker compose build api

Générez une clé locale, démarrez PostgreSQL, Redis et Laravel, puis appliquez les migrations et les données de démonstration :

docker compose run --rm api php artisan key:generate
docker compose up -d
docker compose exec api php artisan migrate --seed --force

Chargez le catalogue ISO des pays et territoires pour le choix du pays dans le profil :

docker compose exec api php artisan db:seed --class=CountrySeeder --force

Vérifiez que l’API répond : ouvrez http://127.0.0.1:8000/up. Le résultat attendu est HTTP 200.

Ne lancez pas migrate:fresh sur une base contenant des données à conserver. Cette commande supprime toutes les tables et leurs données.

3. Préparer et démarrer la PWA

Copy-Item africaquizz-pwa\.env.example africaquizz-pwa\.env
Set-Location africaquizz-pwa
npm ci
npm run dev -- --host 127.0.0.1

La PWA utilise par défaut http://127.0.0.1:8000 comme API. Ouvrez http://127.0.0.1:5173/bienvenue et cliquez sur « Jouer 5 questions ».

Interface équipe : ouvrez http://127.0.0.1:5173/admin/connexion. Après connexion, chaque rôle est dirigé vers son espace : /admin/superadmin, /admin/admin, /admin/relecteur ou /admin/editeur. Le SuperAdmin gère les accès de l’équipe, les catégories et les badges ; l’Admin pilote les joueurs, les indicateurs et l’audit ; le Relecteur contrôle les questions bilingues, leurs sources et les signalements ; l’Éditeur traite les imports, la médiathèque et la publication.

En environnement local Docker, le bypass 2FA est activé pour faciliter les essais. Il est limité aux environnements local et testing et ne doit pas être activé en production. Hors de ces environnements, la configuration et la vérification TOTP restent obligatoires.

En local, le seeder crée cinq questions bilingues de démonstration et quatre réponses par question. Elles permettent de parcourir un quiz sans importer une sauvegarde externe.

Pour créer les comptes de test du guide dans PostgreSQL, renseignez les variables AFRICAQUIZZ_SUPERADMIN_PASSWORD, AFRICAQUIZZ_ADMIN_PASSWORD, AFRICAQUIZZ_REVIEWER_PASSWORD et AFRICAQUIZZ_EDITOR_PASSWORD dans africaquizz-api\.env, puis lancez docker compose exec api php artisan db:seed --class=GuideAccountsSeeder --force. Ne réutilisez pas ces mots de passe en production.

4. Tests automatisés et vérifications manuelles

Depuis le dossier racine du dépôt :

docker compose exec api php artisan test
docker compose exec api php artisan route:list
Set-Location africaquizz-pwa
npm run build

Le test QuizStartTest vérifie qu’un invité peut démarrer une partie, reçoit cinq questions traduites et quatre options par question, et qu’un mode non supporté est rejeté.

Pour tester l’endpoint directement dans PowerShell :

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8000/api/v1/quiz/sessions `
  -ContentType 'application/json' `
  -Headers @{ Accept = 'application/json' } `
  -Body '{"mode":"classic","locale":"fr"}'

La réponse doit contenir data.id et une liste data.questions de cinq éléments.

5. Données de démonstration et sauvegardes

La commande migrate --seed charge automatiquement les questions de démonstration en environnement local ou testing. Pour réinitialiser une base locale jetable uniquement :

docker compose exec api php artisan migrate:fresh --seed --force

Une sauvegarde complète peut contenir des comptes, des mots de passe hachés, des adresses e-mail et d’autres données personnelles. Les fichiers de sauvegarde et les fichiers .env sont exclus de Git et ne sont pas fournis dans le dépôt. N’importez qu’une sauvegarde autorisée, dans une base locale isolée.

6. Dépannage

  • Docker ne répond pas : démarrez Docker Desktop et vérifiez que le moteur Linux est actif.
  • Erreur « could not find driver » : utilisez l’API du conteneur avec docker compose up -d, pas le PHP Windows sans extension PostgreSQL.
  • API HTTP 500 : consultez docker compose logs api et docker compose logs postgres, puis vérifiez que migrations et seeder ont été exécutés.
  • Port 8000 ou 5173 occupé : arrêtez l’application qui l’utilise ou modifiez le port correspondant et l’URL API dans africaquizz-pwa\.env.
  • Arrêter les services : depuis la racine, exécutez docker compose down. Les volumes de données ne sont pas supprimés.

7. Architecture utile au test

  • africaquizz-api : API Laravel et tests PHPUnit.
  • africaquizz-pwa : interface joueur React, TypeScript et Vite.
  • africaquizz-contract : types, exemples et contrat API.
  • docker-compose.yml : API HTTP, PostgreSQL et Redis pour le développement local.
